Redroid limitation
Use explicit HTTP proxy mode. The VPN path is not treated as equivalent in Redroid, and UDP/QUIC visibility remains limited by proxy mode.
Browser-first validation

Chrome / Chromium uses Android trust behavior and may retry over QUIC. The check confirms proxy reachability, forces an honest TCP fallback when required, and then verifies a decrypted HTTPS transaction.

Firefox differs: enable its platform/third-party CA trust behavior when the build does not use Android’s user trust store. The diagnostic names the exact missing trust path instead of reporting a generic TLS failure.
