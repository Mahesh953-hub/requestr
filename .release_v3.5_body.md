# requestr v3.5 — Fix & Release

This release wires the capture-method dispatch architecture and adds durable Flow persistence.

## Highlights

- Dispatches capture methods to real engines: VPN TUN, MITM proxy, HTTP proxy, root iptables, and Shizuku.
- Selects MITM proxy when the requestr CA is installed, making the existing per-host certificate path reachable.
- Applies persisted BLOCK rules in `CaptureEngine`.
- Persists Flow nodes and connections in Room; database schema updated to version 5.
- Fixes onboarding theme selections being ignored after cold boot.
- Clarifies duplicate media/storage permission state.
- Renders HTML note previews instead of raw tags.
- Improves API-save database error handling.

## Build artifacts

- `requestr-v3.5-debug.apk`
- `requestr-v3.5-release.apk` (signed)

## Verification

- Debug and release Gradle builds passed.
- Release APK signature verified.
- Redroid Android 15 smoke test passed for app launch, API Testr (live HTTP 200), Tools, Flow, Intercept, and navigation.

## Verification limitations

No physical Android device was available. Root iptables, Shizuku, Frida injection, third-party app VPN capture, real CA installation/MITM, and Doze survival remain hardware-verification items. See the attached repository report `RELEASE_NOTES_v3.5.md` for the complete item-by-item accounting and explicit blockers.
