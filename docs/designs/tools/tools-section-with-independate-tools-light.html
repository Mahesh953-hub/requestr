How this maps to the rest of the Tool Library
Screen 2's layout (single input → single output) covers: URL Encoder, Hex Converter, HTML Entity Escape, Morse Converter, every Hash tool, HMAC Signer
Screen 3's layout (pixel-tab mode switch) covers: Base64, AES Encrypt/Decrypt (tabs become Encrypt/Decrypt, with extra Key/IV/Mode fields inserted above Input), XOR Cipher
Both patterns share the same field-header action-icon row (paste/clear on input, copy on output) — implement once as a shared component, not per-tool
Header pill is identical across every tool screen: back pill + title/subtitle pill — only the title text changes
